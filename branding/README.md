# Брендинг

Файлы здесь перекрывают стандартные при сборке (`build/bin/copy.js`).
Замените на свои, сохранив имена и размеры:

- `images/electerm.png`, `images/electerm.svg` - основной логотип
- `images/electerm-round-128x128.png` - круглый 128x128
- `images/electerm-watermark.png` - водяной знак на загрузочном экране
- `favicon.ico` - иконка вкладки (копируется в `dist/assets/`)
- `build-res/` - исходные иконки приложения (для десктоп-сборки)
